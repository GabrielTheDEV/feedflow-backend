📋 Como Testar

  1. Execute o backend: cd backend && python main.py
  2. Crie um merchant: python create_merchant.py
  3. Cole o token gerado no campo acima
  4. Clique em "Inicializar Widget"
  5. Procure o botão "Reportar Problema" no canto da tela
  6. Clique no botão e envie um feedback de teste

✨ Funcionalidades

📸 Captura de Tela

Captura automática da tela usando html2canvas, sem necessidade de extensões.

🔒 Multi-Tenancy

Cada lojista tem seus próprios dados isolados via API token.

📊 Metadados Técnicos

Coleta automaticamente user agent, URL, viewport e outras informações.

🎨 Customizável

Personalize cores, posição e textos do widget.
